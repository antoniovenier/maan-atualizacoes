# MAAN Gestão — atualizações

Instaladores do MAAN Gestão, aplicativo interno do escritório MAAN Engenharia.

Este repositório existe por um motivo só: o aplicativo baixa a atualização sozinho, e para
isso precisa de um endereço público e direto para o arquivo. O código-fonte não está aqui.

## Instalar não dá acesso

O programa só abre com uma chave de ativação emitida pelo administrador do escritório.
Sem ela, a instalação para na tela de ativação. Baixar este arquivo não concede acesso a
dado nenhum.

## Versão atual

`MAAN-Gestao-Setup-1.0.3.exe`
